 #  Mind Math Quizzer

An interactive Python application designed to test and improve mental math speed, accuracy, and problem-solving skills under time constraints.

---

## 🌟 Key Features

- ⚡ **Real-time Scoring:** Instant feedback on test speed and accuracy.
- 🎯 **Multiple Difficulty Levels:** Customizable difficulty for addition, subtraction, multiplication, and division.
- 📊 **Performance Analytics:** Comprehensive breakdown of results at the end of each session.
- 🎨 **Interactive Interface:** Clean, user-friendly CLI/UI layout.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework/Libraries:** Streamlit / Tkinter (jo bhi tumne app me use kiya ho)
